# Re:Nav demonstration media

Derived display videos for [Re:Nav](https://aoiota.github.io/Re-Nav/). Release assets contain ten demonstration entries, separate D2/D6 repeats, Chinese/English films, and selected complete replays.

These are research demonstration videos, not scene datasets, model weights or raw databases. Per-run outcomes, protocols and provenance are on the website; selected demonstrations do not establish aggregate benchmark success or causal module benefit. Robot/scene visualizations do not establish Agent use.

See the [website attribution](https://aoiota.github.io/Re-Nav/ATTRIBUTION.md) for asset sources and third-party terms. No additional license to underlying third-party scenes or models is granted by this repository. SHA256SUMS.txt identifies the exact released media.
